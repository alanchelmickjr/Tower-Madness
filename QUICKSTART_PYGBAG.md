# Tower Madness - Pygbag Quick Start

## 🎯 Deploy Python/Pygame to Web in 3 Steps

### Step 1: Build
```bash
python build_pygbag.py
```

### Step 2: Test Locally
```bash
python serve_web.py
```
Open: http://localhost:5000

### Step 3: Deploy
Upload these files to your web host:
- `tower-madness.apk`
- `index_pygbag.html`
